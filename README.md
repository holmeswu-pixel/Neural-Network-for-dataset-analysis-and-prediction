# Neural-Network-for-dataset-analysis-and-prediction
This repository contains three neural network models for analysis of three individual datasets. Each network is written in Python using Pytorch framework. Datasets were acquired from open-source website and in-built dataset in Python.
First network: Simple neural network for prediction of score from selected parameters from dataset.
Second network: Simple neural network for prediction of risk from selected parameters from dataset.
Third network: A Convolutional neural network for recognition of MNIST dataset.
